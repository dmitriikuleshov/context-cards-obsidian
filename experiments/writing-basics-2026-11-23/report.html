The scorer compares resulting source sentences, so different valid target anchors receive the same score. Both exercise formats were generated for selected cases; deletion targets use correction only. No Anki notes or vault files were changed by these audits.

The comparison uses 23 identical cases. The old regional accept-both case is excluded because the user requested American English. A new American-spelling case and 30 additional cases test the new policy, correct-text controls, multiple adjacent errors and migration of removed settings.

Final postprocessing was validated by replaying 216 live analyses: all 412 outgoing request payloads, including card generation, matched the recorded requests exactly. One Qwen 3 regional spelling was found by the model but vetoed as optional; an explicit US spelling policy resolves that disagreement without changing model inputs. A separate fresh six-case live check on all four models validates additional spelling pairs and quoted/code literals.

Hyphenation-only suggestions are treated as style, and a model-added full stop at the selection boundary is ignored. Apostrophe corrections remain eligible. A prompt-only candidate was rejected because it improved Gemma 3 but regressed Gemma 4; correction-first processing resolved the basic omissions. An additional multi-error case exposed an overcautious collocation verdict, addressed with a general example using a different noun.

This is a finite basic regression set. Exact-edit scores do not grade the linguistic precision of every explanation. Feedback was spot-checked. Warm timings in the JSON summary exclude the first case per model; loading and concurrent test activity mean these are descriptive observations.

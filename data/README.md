cmudict.json contains word -> ARPABET pronunciation variants (126,052 entries). Alternate numbered spellings were merged, comments removed, phonemes preserved. IPA conversion and broad stress placement are implemented in src/pronunciation.ts. This is broad dictionary pronunciation, not a narrow transcription of connected speech.

# CMUdict US pronunciation snapshot

- Source: [CMUdict](https://github.com/cmusphinx/cmudict).
- Raw source: [cmudict.dict](https://raw.githubusercontent.com/cmusphinx/cmudict/master/cmudict.dict).
- Retrieved: 2026-11-20.
- Raw SHA-256: `81917843c7f44ce2b094ac63873c2c7a4cf802040792c455ba3ca406891c3d22`.

`cmudict.json` contains word → ARPABET pronunciation variants (126,052 entries). Alternate numbered spellings were merged, comments removed, phonemes preserved. IPA conversion and broad stress placement are implemented in [pronunciation.ts](../src/pronunciation.ts). This is broad dictionary pronunciation, not a narrow transcription of connected speech. When several dictionary variants exist, the model selects one for the current entry; unknown entries and British IPA are generated by the model and need review.

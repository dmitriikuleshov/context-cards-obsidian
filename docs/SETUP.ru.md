# Context Cards: установка, настройка и интерфейс

Инструкция для первого запуска на Windows. Нужны три работающие программы: **Obsidian** для чтения, **Ollama** для генерации и **Anki Desktop** для добавления карточек. BRAT устанавливает и обновляет только плагин Obsidian; Ollama и Anki настраиваются отдельно.

## 1. Скачивание и установка плагина

### Через BRAT — рекомендуемый способ

1. Откройте нужное хранилище в Obsidian.
2. Перейдите в **Settings → Community plugins → Browse**. Если сторонние плагины выключены, сначала разрешите их использование.
3. Найдите **BRAT**, нажмите **Install**, затем **Enable**.
4. Откройте настройки BRAT и нажмите **Add beta plugin**.
5. Вставьте адрес репозитория:

   ```text
   dmitriikuleshov/context-cards-obsidian
   ```

6. Выберите последнюю доступную версию и подтвердите добавление. Если Context Cards не включился автоматически, включите его в **Settings → Community plugins**.
7. Откройте появившийся раздел **Settings → Context Cards**.

BRAT может проверять новые версии и обновлять плагин. Параметры автоматических проверок находятся в настройках BRAT. Не удаляйте установленный Context Cards перед обновлением: так сохранятся его настройки и черновики.

### Вручную из ZIP

Если не хотите устанавливать BRAT:

1. Откройте [последний релиз](https://github.com/dmitriikuleshov/context-cards-obsidian/releases/latest).
2. В **Assets** скачайте **context-cards-ВЕРСИЯ.zip**. Автоматический архив **Source code** для установки не подходит.
3. Распакуйте папку `context-cards` в `<ваше хранилище>/.obsidian/plugins/`. Если папки `plugins` нет, создайте её.
4. Проверьте вложенность: файл должен находиться по пути `.obsidian/plugins/context-cards/main.js`, без второй папки `context-cards` внутри.
5. Перезапустите Obsidian и включите **Context Cards** в Community plugins.

Для обновления вручную выключите плагин, замените `main.js`, `manifest.json`, `styles.css` и сопутствующие инструкции/уведомление CMUdict из нового архива. Сохраните существующий **data.json**: в нём находятся ваши настройки и черновики. Включите плагин снова.

## 2. Ollama: локальная нейросеть

### Установка программы и модели

1. Скачайте [Ollama для Windows](https://ollama.com/download/windows), установите и запустите её.
2. Откройте **PowerShell** или **Windows Terminal** через меню «Пуск». Если терминал был открыт до установки, откройте новое окно.
3. Выполните команду загрузки модели:

   ```powershell
   ollama pull qwen3.5:9b-q4_K_M
   ```

4. Дождитесь окончания загрузки. Это отдельная загрузка модели объёмом в несколько гигабайт; скорость зависит от интернета. Для хранения модели нужно свободное место на диске, а для генерации — достаточная память. Скорость на другом компьютере может отличаться от нашей тестовой конфигурации с RTX 5070 и 32 ГБ RAM.
5. Проверьте, что модель установлена:

   ```powershell
   ollama list
   ```

   В списке должно быть имя `qwen3.5:9b-q4_K_M`.

Ollama должна быть запущена во время генерации. Обычно приложение запускает сервер само. Если оно уже работает, дополнительно выполнять `ollama serve` не нужно.

### Подключение в Obsidian

В **Settings → Context Cards → Local model** задайте:

| Настройка | Начальное значение |
| --- | --- |
| Ollama server | `http://127.0.0.1:11434` |
| Model | `qwen3.5:9b-q4_K_M` |
| Generation temperature | `0.2` |
| Request timeout | `60 seconds` |

Нажмите **Check connection** в строке **Check Ollama**. Должен появиться список установленных моделей. Проверка соединения ещё не запускает генерацию: успешное подключение не гарантирует, что модели хватит памяти.

Первый запрос может идти дольше из-за загрузки модели в память. Если запрос обрывается по тайм-ауту, попробуйте `120 seconds`. Если модель не помещается в память или работает слишком медленно, можно выбрать другую уже установленную модель, но качество и соблюдение формата могут измениться.

При стандартных адресах текст обрабатывается локально. Если заменить адрес Ollama на другой сервер, выделение и контекст будут отправляться туда.

## 3. Anki: подключение и повторение

### Anki Desktop и AnkiConnect

1. Установите [Anki Desktop с официального сайта](https://apps.ankiweb.net/) и запустите его.
2. Откройте **Tools → Add-ons → Get Add-ons**. В русской локализации названия меню могут отличаться: нужны «Инструменты», «Дополнения» и получение дополнений.
3. Вставьте код AnkiConnect:

   ```text
   2055492159
   ```

4. Подтвердите установку и перезапустите Anki. [Страница AnkiConnect](https://ankiweb.net/shared/info/2055492159).
5. Оставляйте Anki открытым при отправке карточек из Obsidian. Одного установленного приложения на телефоне для подключения недостаточно.

### Подключение в Obsidian

В **Settings → Context Cards → Anki** задайте:

| Настройка | Начальное значение |
| --- | --- |
| AnkiConnect server | `http://127.0.0.1:8765` |
| AnkiConnect API key | Пусто, если ключ отдельно не настроен в AnkiConnect |
| Default deck | `English::Books` |
| One deck per book | Включено |
| Note type | `Context Cards` |

Нажмите **Check connection** в строке **Check Anki**. Плагин должен показать число найденных колод. Эта проверка не создаёт карточки или колоды.

Колоду и тип заметки не обязательно создавать вручную: плагин подготовит их при первом согласованном добавлении. По умолчанию для каждого Markdown-файла используется отдельная подколода. Например, файл `The Call of Cthulhu.md` получит колоду `English::Books::The Call of Cthulhu`.

### Проверка первой заметки

1. Откройте Markdown-текст в Obsidian, выделите слово и нажмите **Create cards**.
2. Дождитесь черновика, проверьте его и нажмите **Add to Anki** во вкладке **Edit**.
3. После сообщения **Two cards added to Anki** нажмите **Open in Anki** или откройте браузер заметок в Anki.
4. Проверьте оба упражнения: **Recognition** и **Recall**. Это две карточки одной заметки, а не две отдельные заметки.

Для повторения на телефоне синхронизируйте Anki Desktop с вашим AnkiWeb-аккаунтом, затем выполните синхронизацию в AnkiDroid или AnkiMobile. Генерация и добавление происходят на компьютере; на телефоне вы повторяете уже созданные карточки. При желании включите **Bury siblings** в Anki, чтобы родственные упражнения не шли подряд.

## 4. Обзор интерфейса

### Выделение и черновики

Читайте Markdown в **Reading Mode** или **Live Preview**. Выделите слово/выражение и нажмите всплывающую кнопку **Create cards**. Также доступны команды Context Cards через палитру команд Obsidian.

Справа откроется панель с черновиком. Сверху можно переключаться между последними **четырьмя** черновиками. При добавлении пятого самый старый удаляется из списка. **Clear all** очищает список и отменяет текущую генерацию, но не удаляет заметки из Anki. Ещё не отправленный текст в удалённых черновиках будет потерян.

### Edit: поля карточки

Все учебные поля заполняются на английском и доступны для ручной правки. Отключённые в настройках поля не показываются.

| Поле | Что в нём |
| --- | --- |
| Word or expression | Словарная форма слова или устойчивого выражения. Может отличаться от формы в книге. |
| Grammar | Часть речи или грамматическая характеристика, например `plural noun`. |
| American IPA / British IPA | Транскрипция отображаемого слова. Вариант выбирается в настройках. |
| Meaning in this context | Значение именно в исходном отрывке. Оно служит скрытой подсказкой для Recall. |
| General meaning | Общее значение словарного слова без привязки к отрывку. |
| Word formation | Исходное слово и его общее значение, например `conceive — …`. Без разбора приставок и суффиксов; может оставаться пустым. |
| Context from your book | Отрывок из книги, достаточный для понимания выбранного употребления. |
| Explanation | Пояснение употребления и нюансов выбранного смысла. |
| Examples | Группы значений/употреблений с примерами. Число групп выбирает модель в заданных пределах; для слова с одним значением достаточно одной группы. |
| Usage notes | Краткие замечания, сочетания и особенности употребления. |

В строке **Answer** хранится точная форма из источника, которую нужно вписать в Recall. Например, заголовок — `brush off`, а ответ по книге — `brushed off`.

Если ответ выбран неправильно, раскройте **Answer**, выделите нужный фрагмент в поле контекста и нажмите **Use selection as answer**. Эта кнопка меняет ожидаемый ответ на ваше выделение. **More context** добавляет окружающий текст из сохранённого снимка источника; при необходимости отредактируйте контекст вручную и повторите генерацию.

### Anki destination

Раскройте этот блок, чтобы выбрать **Deck** и изменить **Tags**. **Refresh decks** перечитывает список колод из Anki. Если вы переименовали колоду, новое имя появится в списке, но его нужно выбрать самостоятельно: текущий адрес назначения автоматически не заменяется.

### Нижние кнопки Edit

- **Generate draft / Regenerate** — создать или повторно сгенерировать учебное содержимое. Если предложена новая версия, **Apply new version** применяет её, а **Keep my draft** оставляет текущие правки.
- **Add to Anki** — отправить согласованную заметку. Доступность зависит от заполнения обязательных включённых полей и корректности ответа в контексте.
- **Корзина** — удалить текущий черновик. Уже отправленные заметки в Anki эта кнопка не удаляет.

Модель может ошибаться в значениях, транскрипции и примерах. Редактирование и согласование нужны именно для проверки результата.

### Preview: два упражнения

В **Preview** нет кнопок генерации и отправки: они находятся в Edit. Используйте **Recognition**, **Recall** и **Flip card**, чтобы посмотреть стороны карточек.

- **Recognition:** сначала видно слово/выражение. **Show context** раскрывает исходный отрывок. После переворота показываются включённые учебные поля.
- **Recall:** виден исходный отрывок с пропуском. **Show definition** раскрывает контекстное определение. Нужно восстановить исходную форму, а не обязательно словарную форму из заголовка.

В Preview поле ввода показывает устройство упражнения. Окончательное сравнение введённого ответа с правильным выполняет Anki во время повторения.

### Настройки полей и чтения

В **Settings → Context Cards → Card fields** можно включать/выключать поля, выбрать вариант IPA, число предложений, максимум групп и количество примеров. Чтобы новые количества и вариант произношения применились к текущему черновику, нажмите **Regenerate** и согласуйте новую версию. Простое отключение скрывает поле, не стирая его текущий текст. Уже отправленные заметки не перегенерируются.

Если выключить **Context from your book**, обычный показ контекста исчезнет, но Recall сохранит отрывок с пропуском: без него упражнение невозможно. Если выключить **Meaning in this context**, скрытой подсказки-определения не будет.

В **Reading workflow** находятся переключатели всплывающей кнопки, восстановления черновиков и **Mark selected word as inline code**. Последний оборачивает слово обратными кавычками в исходном Markdown при Create cards; по умолчанию выключен.

Внизу настроек **Reset to defaults** возвращает все параметры к исходным, включая подключения и сохранённые назначения колод. Черновики и Anki-заметки остаются.

### Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| Нет кнопки Create cards | Выделение в Markdown, режим чтения/Live Preview и настройку Selection button. Можно воспользоваться командой из палитры. |
| Плагин не появился после установки | Включение в Community plugins; при ZIP-установке — правильную вложенность папок. |
| Ollama недоступна | Запущена ли программа, правильны ли URL и имя из `ollama list`. |
| Генерация долго идёт или завершается ошибкой | Первый запуск модели, свободную память и тайм-аут. Проверка соединения не проверяет доступность памяти для генерации. |
| Anki недоступен | Открыт ли Anki Desktop, установлен ли AnkiConnect, правильны ли URL и API key. |
| Кнопка Add to Anki недоступна | Сообщение внизу Edit, обязательные включённые поля, ответ в контексте, неподтверждённую новую версию или предупреждение о дубликате. |

Официальные справки: [Ollama на Windows](https://docs.ollama.com/windows), [AnkiConnect](https://ankiweb.net/shared/info/2055492159), [синхронизация Anki](https://docs.ankiweb.net/syncing.html), [BRAT](https://github.com/TfTHacker/obsidian42-brat).

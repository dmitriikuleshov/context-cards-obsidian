CONTEXT CARDS — QUICK SETUP

Requires Obsidian Desktop 1.8.0+; ChatGPT sign-in requires 1.11.5+.
Windows is tested. Mobile Anki can review synced cards; mobile Obsidian is not supported.

Full English guide with screenshots:
https://github.com/dmitriikuleshov/context-cards-obsidian/blob/main/docs/SETUP.md

RECOMMENDED: BRAT
In Obsidian Community plugins, install and enable BRAT.
Open BRAT settings > Add beta plugin, and enter:
dmitriikuleshov/context-cards-obsidian
Select the latest version, add it and enable Context Cards if needed.
BRAT can also update the plugin. Continue with OLLAMA and ANKI below.
Existing users: do not uninstall Context Cards first; keep your data.json.

ALTERNATIVE: ZIP

Download context-cards-VERSION.zip from:
https://github.com/dmitriikuleshov/context-cards-obsidian/releases/latest
Do not use the automatic Source code ZIP: it has no compiled plugin.

1. Extract the ZIP and copy context-cards into YOUR_VAULT/.obsidian/plugins/.
   main.js must be directly inside context-cards, not another nested folder.
2. Restart Obsidian and enable Context Cards under Settings > Community plugins.

OLLAMA

Choose Settings > Context Cards > AI connection > Provider > Ollama.
Install and open Ollama: https://ollama.com/download/windows
In a new PowerShell window, download the recommended starting model:
  ollama pull gemma4:12b-it-qat
Check its installed name:
  ollama list

FOUR TESTED MODELS (choose one)
  gemma4:12b-it-qat       Recommended for vocabulary and Find mistakes.
  qwen3.5:9b-q4_K_M      Smaller option; the plugin's built-in default.
  gemma3:12b-it-q4_K_M   Alternative; check base words and explanations.
  qwen3:14b-q4_K_M       Slower in our tests, with no clear quality advantage.
To download an alternative, use: ollama pull EXACT_MODEL_TAG
The full guide includes commands, download sizes and recorded comparison results.
Tests used Windows, RTX 5070 12 GB and 32 GB RAM, with thinking disabled.
Review model output; a correct edit can still have an inaccurate explanation.

In Settings > Context Cards > Local model:
  Ollama server: http://127.0.0.1:11434
  Model: select gemma4:12b-it-qat after downloading it, or your chosen model
  Request timeout: 60 seconds; try 300 or 600 on slower hardware.
The model list loads automatically. Use Refresh beside Model after installing
or removing a model. If Ollama is unavailable, your saved choice is kept.
Keep Ollama running while generating content.

OPTIONAL: CHATGPT SUBSCRIPTION (PREVIEW)

Requires Obsidian 1.11.5+ with Secret storage and an eligible ChatGPT account.
Choose AI connection > Provider > ChatGPT > Continue with ChatGPT.
Sign in in your browser and grant permission to use your plan.
On Authorization received, return to Context Cards settings in Obsidian and
check for Connected or an actionable error, then choose a ChatGPT model.
You can close the callback tab; it does not need to stay open.
Refresh models reloads account-specific choices. Manage usage opens your limits.
This uses your shared ChatGPT allowance, with no API-key billing fallback.
Any extra credit use follows the permissions in your ChatGPT account.
Selected text and context are sent to OpenAI. Account eligibility still applies.
Credentials use Obsidian Secret storage; sign-in refreshes automatically.
Sign out clears local credentials and attempts remote session revocation.
Use Provider > Ollama to return to local generation.

ANKI

Install and open Anki Desktop: https://apps.ankiweb.net/
Choose Tools > Add-ons > Get Add-ons and enter 2055492159 for AnkiConnect.
Restart Anki and keep it open while checking connections or adding cards.

In Settings > Context Cards > Anki:
  AnkiConnect server: http://127.0.0.1:8765
  API key: blank unless configured in AnkiConnect.
Use Check connection in the Check Anki row.
The plugin creates its deck and note type on the first approved export.

THE TWO ACTIONS

Explain word / phrase:
Select one word or expression in a Markdown book. Review the English draft,
preview it, then use Add to Anki in Edit. One note creates Recognition and
Recall cards. Recall asks for the original source form.

Find mistakes:
Select a paragraph of your writing. Click highlighted expressions to review
the corrections and choose which grammar/vocabulary findings become cards.
Click Review N cards, check the exercises, then Add N cards to Anki.
One chosen correction creates one card. Exporting also saves a Markdown review.

Both modes have a draft selector, Clear all and Open source.
Sync Anki Desktop through AnkiWeb to review the cards on your phone.

UPDATES
Disable the plugin; replace main.js, manifest.json and styles.css; update the
included documentation/CMU notice, and enable the plugin again.
Keep your existing data.json: it stores settings, the optional AnkiConnect
API key and drafts. ChatGPT credentials use separate Obsidian Secret storage.

Requires desktop Obsidian; currently tested on Windows. Review synced cards
in mobile Anki normally. No build tools are needed to install a release.
Optional source marking edits original Markdown. Review model answers.
